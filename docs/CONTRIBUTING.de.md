# Mitwirken

Beiträge sind willkommen! Bitte:
1. Forken Sie das Repository
2. Erstellen Sie einen Feature-Branch
3. Fügen Sie Tests für neue Funktionen hinzu
4. Stellen Sie sicher, dass alle Tests bestehen: `pytest`
5. Formatieren Sie den Code: `black .` und `ruff check .`
6. Senden Sie einen Pull-Request
