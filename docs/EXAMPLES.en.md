# Example Outputs

This page shows examples of documents generated by the Academic Document Generator.

## Thesis Colloquium Letter (Protocol)

The tool generates a formal `scrlttr2` letter using the TH Köln corporate design.

```latex
\documentclass[11pt,ngerman,parskip=full]{scrlttr2}
% TH Köln letterhead
\setkomavar{subject}{Evaluation of Bachelor Thesis by Max Mustermann}

% Summary
\textbf{Summary of the Thesis:}
The work covers...

% Questions
\textbf{Questions Prof. Dr. Müller:}
Page 5: Could you further justify the choice of this methodology?
Page 12: How does the algorithm behave with larger datasets?
```

## Peer Review Comments

Review feedback is output as a structured Markdown document.

```markdown
# Peer Review

- Page 1, Line 15: This point requires clarification...
- Page 2, Line 42: The explanation could be clearer by...
- Page 3, Line 78: The authors should consider recent work by...
```
